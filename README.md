# Hangman Game (Python Terminal Version)

A simple command-line version of the classic *Hangman Game* built in Python.

## Features

- Randomly selects a word from a predefined list.
- Allows the player to guess letters one at a time.
- Displays the current progress of the word.
- Shows remaining attempts.
- Game ends when the word is guessed or attempts run out.
